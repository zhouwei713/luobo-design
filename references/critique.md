# 自己看图：五个维度打分

check.py 只管硬指标。出图后你要像设计总监一样把每张图看一遍，打开 overview.png 看整体，再打开单张看细节。

## 五个维度，每项 1 到 5 分

1. **一眼看懂**：三秒内能不能看出这是什么店、什么事、有什么好处。标题和优惠是不是画面里最先看到的两样东西
2. **层级**：大中小三级字号是否分明，信息有没有挤成一团，视线顺序是不是 标题、产品或优惠、信息、行动
3. **完成度**：对齐、留白、边距是不是整齐，产品图有没有白边、锯齿、被裁，贴纸有没有挡住重要的东西
4. **贴合这家店**：换一个店名还能不能直接用。好的设计带着这家店的具体信息和气质，套模板的感觉越重分越低
5. **克制**：颜色、字体、装饰有没有过量。强调色超过两处、装饰抢了标题、每个角落都塞满，都要扣分

任何一项低于 3 分就改，改完重出再打分，最多三轮。三轮后还有低于 3 分的，交付时如实告诉用户哪里不理想、建议怎么做（比如"产品插画比较简单，有实拍照片换上效果会好很多"）。

## 常见的 AI 味，看到就改

- 紫蓝渐变、霓虹光效，和行业无关的科技感
- 用 emoji 当图标
- 编出来的数据和好评（"已售 10 万杯""好评率 99%"）
- 空话套话（"品质生活从这里开始""匠心之选"）
- 每个元素都加阴影、描边、渐变
- 中英文混排时英文只是装饰，没有意义（"DELICIOUS LIFE"）
- 标题居中、副标题居中、所有东西都居中，没有一个视觉重心

## 怎么改

改动都落在 spec.json 上，然后重跑 pipeline。

- 换版式：改 item.layout
- 换方向：改 brand.direction（整单一起换）
- 字太挤：删文案，或者把 details 挪一行到 cta
- 产品太小或太假：给 art.image 换成实拍图或生图
- 颜色不对：在 brand.tokens 里只改 accent，别动其他

渲染出来的 HTML 在 out/src 里，极少数需要微调的位置可以直接改 HTML 再用 Chromium 截图，但优先改 spec，保证下次能复现。
