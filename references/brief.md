# 从一句话到需求表

## 需求表的五类

拿到用户的话，先拆成下面五类，写进 spec.json 的 `profile`。

- 用户说了的（confirmed）：原话里明确有的，比如"奶茶店""下周开业""小区门口"
- 推断的（inferred）：从常识和行业包推出来的，比如"受众是小区居民和学生"
- 用了默认值的（defaulted）：没说但必须有，你按行业包给了默认值，比如"开业优惠写第二杯半价"
- 还缺的（missing）：要上画面但没有的事实，比如电话、具体日期
- 矛盾的（conflicted）：前后说法对不上，比如"要高级感"又要"越热闹越好"

推断和默认值要在交付时说一句，用户才知道哪些可以改。

## 接不住的需求，开工就说

有些东西排版程序和生图模型都做不好，硬做出来用户会失望。听到下面这些，在需求表这一步就跟用户讲清楚能做到哪一步、换个什么做法，别等出图了再解释。

| 需求 | 为什么接不住 | 换个做法 |
|---|---|---|
| 真人出镜的照片（穿搭、自拍、探店本人、医美前后） | 生成的人像冒充本人迟早出事，前后对比还涉及广告法 | 用户发自己的照片来，我们排版、加花字 |
| 餐厅招牌菜的大片 | 模型画的菜和店里端上来的对不上，顾客会觉得被骗 | 用店里实拍；没有就做纯文字或插画版的菜单海报 |
| 某个知名 IP、卡通形象、别家品牌的 logo 或包装 | 版权问题，画像了也不能商用 | 用我们自己设计的形象和程序插画 |
| 仿照某张现成海报一比一复刻 | 抄设计，而且对方的字体图片都有版权 | 学它的思路，重新想一个画面 |
| 公章、奖章、证件、票据、收据 | 仿制公章和凭证违法 | 证书只留“盖章处”；票据请用正规系统开 |
| 要真实地图截图做精确导航 | 我们画的是示意，不能当导航用 | 写清地址，附上地图 App 的链接或二维码 |
| 视频、动图、实况照片 | 这个 skill 只出静态图和 H5 | 交给做视频的工具；可以先出封面和分镜用的画面 |
| 需要具体数据的长图报告、复杂图表 | 版式是给宣传物料设计的，表格能力有限 | 数据量大的交给做表格或 PPT 的工具 |

用户坚持要做时，说明风险，做能做的那部分，在交付时再提醒一次。

## 问不问，问什么

能做就先做。下面三种情况才问，按影响大小排序，一轮最多 3 题。

1. 用途不清楚，不知道该出哪些物料或尺寸（比如只说"做个图"）
2. 关键事实缺失，而且没有它物料就没法用（开业海报没有日期，价目表没有价格）
3. 有矛盾，选哪边会让设计完全不同

每题都给推荐答案，并说明不回答就按推荐的来。选项用用户自己的说法，别用设计术语。

不要问的：风格偏好（你来推断，一句话说出来）、配色、字体、版式。这些是设计师的活。

电话、地址、二维码这类可以晚点补的，不必为它们拦住出图，留占位，交付时列出来。

## 文案怎么写

用户一般只给信息，不给文案。标题、副标题、行动句由你来写，写之前先想清楚这张图要让看的人做什么。

- 标题说人话，说具体的事，"小区门口开了家奶茶店"比"盛大开业 敬请光临"有用得多
- 标题按意思手动断行（spec 里用 `\n`），每行 8 个字以内最好看，最多两到三行
- 优惠单独放进 offer，大字只写最核心的几个字（"第二杯半价"），条件和日期放小字
- 行动句告诉人具体做什么（"到店出示这张图，免费加一份珍珠"）
- 不写极限词和功效承诺，不写编出来的数字（"已售十万杯"这种用户没说过的话）
- 用户给的店名、活动名、口号一字不改

## 尺寸怎么选

按"这张图会出现在哪"来定，不要一股脑全出。

| 用户的说法 | 尺寸 |
|---|---|
| 发朋友圈、发群里 | portrait（3:4）、square |
| 发小红书 | portrait |
| 手机上转发的长海报 | story（9:16） |
| 店里贴、打印 | a4，大的橱窗海报用 a3 |
| 店里电视、收银屏 | landscape |
| 桌面价目卡、小传单 | a5 |

用户没说用在哪时，海报默认 portrait + square + a4，菜单默认 a4 + story。

## 视觉方向：挑三个给用户看

先看行业包里的推荐，再看用户的形容词。"高级""有格调"往 clean-minimal、editorial、dark-premium 走；"热闹""喜庆"往 pop-fresh、festive-red 走，婚礼寿宴这类喜事往 xi-red 走；"国风""茶""节气"往 guochao 走；"温暖""手作"往 warm-hand 走。

三个候选要拉开差距，最好分别来自三个温度组，热闹组（pop-fresh、festive-red、sport-bold）、中间组（warm-hand、soft-pastel、campus-fresh、guochao、trust-blue、garden-romance、xi-red）、安静组（clean-minimal、editorial、dark-premium）。第一个放你最推荐的。directions.py 会自动给每个方向配不同的版式。

不要用文字描述让用户选风格，也不要连问"喜欢什么颜色""要什么感觉"。把三张图摆出来，用户一眼就知道要哪个。用户有 brand.json 时直接沿用，不再出三版。
