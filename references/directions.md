# 二十一个视觉方向

数据在 directions.json，这里讲什么时候用哪个。每个方向都定死了六个颜色、标题和正文字体、圆角、底纹、质感和配图风格。用户有自己的品牌色时，在 spec.brand.tokens 里覆盖强调色就行，别的保持不变。

方向只管颜色、字体和质感，海报长什么样主要看概念和版式（SKILL.md 第二步）。三个候选按稳妥、概念、大胆出，素净组最适合给稳妥款和信息类物料配色。

## 素净组

素净组（jing-* 加 clean-minimal、editorial、dark-premium）是信息类物料和稳妥款的主力。它的做法写在 poster-craft.md 的“素净是怎么做出来的”一节：

- 标题用有性格的中文字，宋体 700、得意黑或黑体 800，不用细到发虚的西文字体
- 店名和日期竖排在右边一条
- 海报下半张是一整块强调色，优惠、日期、地址反白排在里面；请柬的封面是一整块强调色，名字和日期在上面
- 底色干净不发灰，强调色饱和
- 平涂和纸张质感，不用渐变、毛玻璃、圆角卡片、阴影；有真照片放直角方框，没照片让标题撑画面

这组在 spec 里不写 layout 时，海报自动用 jing 版式，通知自动用对应的精修版。请柬、证书、名片、桌号牌、席位名牌、菜单和电子请柬选了这组方向，也会换成同样的排法，layout 写的 formal、number、tent 这些只当提示用（tent 仍然是对折名牌）。喜事想要安静一点就用胭脂，想要满版大红仍然用 xi-red。

旧版本的书卷组和细线组（mag-*、swiss-*）已经并进素净组，旧 id 还能用，会自动换成最接近的新方向：mag-ink 到水墨，mag-indigo 和 swiss-blue 到黛蓝，mag-forest 和 swiss-green 到竹青，mag-night 到玄青，mag-xi 到胭脂，swiss-orange 到赭石，swiss-yellow 到姜黄。

## 怎么选

先看行业包的推荐顺序，再看三件事。

1. 用户的形容词。"高级""有格调""简约"往素净组走，排除 pop-fresh 和 festive-red；"热闹""喜庆""可爱"走 pop-fresh、festive-red、campus-fresh，也可以给一个赭石或姜黄当稳妥选项
2. 物料放在哪。门店墙上远看的海报要对比强、字大，pop-fresh、festive-red、sport-bold 更合适；朋友圈和小红书近看，clean-minimal、warm-hand、editorial 的细节才看得出来
3. 店本身的样子。用户发了门头或店内照片，配色要和店里对得上

## 版式和方向的搭配

- jing 是素净组自己的版式，有照片放照片方框，没照片靠标题和信息色块撑画面
- concept 是你亲手构图的概念版式，所有方向都能用，见 item-concept.md
- product-hero 适合有一个明星产品的店，所有方向都能用
- type-hero 靠大字取胜，配 pop-fresh、festive-red、sport-bold、trust-blue 最有力
- editorial 靠留白和细线，配 editorial、dark-premium、guochao、clean-minimal
- notice 只为把事说清楚，所有方向都能用，trust-blue 和 clean-minimal 最稳
- photo-full 必须有好照片（用户提供或生图），配 dark-premium、clean-minimal、warm-hand

同一单里的多件物料用同一个方向，版式可以不同。

## 热闹的方向也别堆东西

pop-fresh、campus-fresh、festive-red、sport-bold 这四个保留了星星、光芒这类装饰，因为开业、节日、亲子活动需要热闹。其余方向这些装饰默认关掉。热闹也要成体系：一种强调色当主角，装饰只在一两处，标题照样只有一个焦点。
