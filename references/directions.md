# 十三个视觉方向

数据在 directions.json，这里讲什么时候用哪个。每个方向都定死了六个颜色、标题和正文字体、圆角、底纹、质感和配图风格。用户有自己的品牌色时，在 spec.brand.tokens 里覆盖强调色就行，别的保持不变。

| id | 名字 | 一句话 | 常见行业 |
|---|---|---|---|
| pop-fresh | 元气撞色 | 黄底番茄红，贴纸感，热闹好吃 | 奶茶、小吃、开业促销 |
| warm-hand | 暖手作 | 奶油底陶土红，文楷，纸张质感 | 烘焙、咖啡、手作、家常菜 |
| clean-minimal | 清爽极简 | 米白底墨绿点缀，留白取胜 | 精品咖啡、轻食、工作室、个人品牌 |
| editorial | 杂志感 | 粗宋体大标题，细线分隔，像杂志版面 | 讲座、读书会、自媒体、品牌发布 |
| dark-premium | 黑金质感 | 深炭底香槟金，宋体，颗粒质感 | 酒吧、高端餐饮、年会、会员活动 |
| guochao | 新中式 | 宣纸底朱砂红松石绿，小薇体，祥云纹 | 新中式茶饮、茶馆、节气、春节 |
| trust-blue | 稳重专业 | 浅灰底藏青，粗黑体，网格 | 律所、财税、咨询、企业通知 |
| soft-pastel | 柔和治愈 | 浅粉底薄荷绿，大圆角 | 美业、甜品、母婴、宠物 |
| sport-bold | 动感力量 | 黑底荧光绿，斜体粗字，斜条纹 | 健身、瑜伽、赛事 |
| campus-fresh | 校园清新 | 天空蓝向日葵黄，文楷，方格本 | 教育培训、老师、家长会 |
| festive-red | 喜庆红 | 中国红底金黄字，放射光芒 | 开业、年会、春节、周年庆 |
| xi-red | 喜事红 | 正红底金字，细金框，囍字，清秀的标题宋 | 中式婚礼、订婚、寿宴、满月宴 |
| garden-romance | 森系浪漫 | 象牙白底橄榄绿配豆沙粉，细线边框，清秀的标题宋 | 婚礼、订婚、满月宴、花店、下午茶 |

## 怎么选

先看行业包的推荐顺序，再看三件事。

1. 用户的形容词。"高级"排除 pop-fresh 和 festive-red，"热闹"排除 clean-minimal 和 editorial
2. 物料放在哪。门店墙上远看的海报要对比强、字大，pop-fresh、festive-red、sport-bold 更合适；朋友圈和小红书近看，clean-minimal、warm-hand、editorial 的细节才看得出来
3. 店本身的样子。用户发了门头或店内照片，配色要和店里对得上

## 版式和方向的搭配

- product-hero 适合有一个明星产品的店，所有方向都能用
- type-hero 靠大字取胜，配 pop-fresh、festive-red、sport-bold、trust-blue 最有力
- editorial 靠留白和细线，配 editorial、dark-premium、guochao、clean-minimal
- notice 只为把事说清楚，所有方向都能用，trust-blue 和 clean-minimal 最稳
- photo-full 必须有好照片（用户提供或生图），配 dark-premium、clean-minimal、warm-hand

同一单里的多件物料用同一个方向，版式可以不同。
