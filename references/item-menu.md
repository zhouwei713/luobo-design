# 物料：价目表和菜单

type 是 `menu`。餐饮菜单、美业价目表、健身课程价格、培训课程表都可以用。

## 内容字段

| 字段 | 说明 |
|---|---|
| title | 大标题，"今日菜单""价目表""MENU" |
| subtitle | 一句说明，比如甜度、规格、温馨提示 |
| sections | 分组，`[{"name": "招牌奶茶", "note": "中杯 / 大杯", "items": [...]}]` |
| items | `{"name": "满满珍珠奶茶", "price": "12", "desc": "黑糖现煮珍珠", "tag": "招牌"}` |
| details | 底部信息行，地址、营业时间、电话 |
| note | 底部小字，"图片仅供参考，以实物为准" |
| qr | 扫码点单、扫码进群 |

价格只写数字，¥ 会自动加。做课程表、值日表这类不带价格的清单时，price 不填，时间和老师写在 desc 里。多规格写成 "12/15"，并在分组 note 里写"中杯 / 大杯"。tag 只给少数几个（招牌、新品、推荐），全标等于没标。

## 两种版式

**list** 经典菜单。分组标题加粗线，菜名和价格之间是点线。程序会自动试 1 列、2 列（横版试到 3 列），选字最大的一种，再把多出来的高度均匀分给每一行，整页排满不留大空。六道以内的分组不会被拆到两列，保证每道菜都在自己的分组标题下面。横版时左边是店名、插画、信息，右边是菜单。

**cards** 每个分组一张白卡片，更有层次，适合分组少、每组菜少的店。

## 尺寸

- a4：打印贴墙、放桌上，导出 PDF 可以直接给打印店
- a5：桌面小价目卡
- story：发群、发朋友圈
- landscape：收银台和店内电视

## 菜品多了怎么办

二十道以内 A4 一张很舒服。二三十道时字会缩小，检查脚本会在低于印刷最小字号时报错，这时拆成两份（比如饮品一份、小吃一份）或者改用 a3。超过四十道直接拆。

## 价格和合规

价格必须来自用户，一个都不编。写了"原价"要有真实原价。会员价、套餐价写清条件。
