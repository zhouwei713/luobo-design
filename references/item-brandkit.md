# 物料：logo 和品牌套件

type 是 `brandkit`，layout 是 `board`。给新店、新账号、新工作室起一套标识。

## 内容字段

| 字段 | 说明 |
|---|---|
| name | 品牌名，必填 |
| tagline | 一句话定位，会出现在文字标和组合标里 |
| monogram | 图形标里用的单字，默认取名字的第一个字，建议挑最有代表性的那个字 |
| name_en | 英文名，可选 |

art.motif 给组合标当图标，从插画库里挑一个和行业相关的（比如 microphone、scales、lotus）。

## 交付什么

- 三个 logo 方案，放在 out/logos 里
  - A 文字标：名字加一个强调色元素，下面是 tagline
  - B 图形标：单字放进形状里（圆、圆角方、印章方，按视觉方向自动选），下面是名字。另有只含图形的 B-emblem-icon，用作头像和 App 图标
  - C 组合标：插画图标在左，名字和 tagline 在右，横向排列
- 每个方案都有正常版和反白版（放在深色或强调色上用），格式是 SVG 和透明底 PNG
- 一张品牌板 PNG：三个方案、六个颜色和色值、字体样张、头像和名片的使用示意
- brand.md 和 brand.json：以后做任何物料都读它

SVG 里的文字已经转成轮廓，换电脑打开也不会变字体。转轮廓需要 Python 的 fontTools 和 brotli，缺了会退回普通文字并提示。

## 怎么配合三方向

品牌起盘最适合先跑 directions.py 选方向：同一个名字在三个方向里出三张品牌板，用户挑一个，再在那个方向里从 A、B、C 三个 logo 里挑一个。

## 和生图配合

想要更独特的图形，用 prompts.md 里的 logo 提示词，让生图模型只画图形、不写字，一次出九个方案。用户挑中以后，把图形抠出来放进 art.image，再和文字标组合。中文字标始终用真实字体，不让模型写。

## 注意

- 不模仿任何现有品牌的 logo，名字和图形撞了知名品牌要提醒用户
- 商标注册前建议用户自己去商标局查一下近似商标
- 字体都是 OFL 等开源授权，可以商用；用户换成自己的字体时要确认授权
