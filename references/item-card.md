# 物料：名片

type 是 `card`。一个 item 自动出正反两面。

## 内容字段

| 字段 | 说明 |
|---|---|
| name | 姓名，必填 |
| name_en | 英文名或拼音，可选 |
| title | 职位头衔 |
| org | 机构名，和品牌名一样时自动省略，避免重复 |
| contacts | `[{"k": "手机", "v": "139 0000 0000"}, {"k": "邮箱", "v": "..."}]`，三四行最合适 |
| qr | 二维码，`{"label": "微信", "src": "wechat.png"}` |
| slogan | 背面的一句话 |

正面放人和联系方式，背面放品牌（logo 或文字标）和 slogan。

## 两种版式

**classic** 左上姓名头衔，右上品牌，底部联系方式，干净稳重。

**band** 左边一条强调色竖带，其余同 classic，更有识别度。

## 尺寸

- card：90x54mm 横版，含 2mm 出血，导出 PNG（300dpi）和 PDF，PDF 可以直接给印刷厂
- card-v：54x90mm 竖版

文字都在安全区里，背景色铺到出血边，裁切后不会露白边。

## 注意

- 二维码要真的能扫：名片上至少 15mm 见方，版式已经按这个尺寸留位置
- 手机号按 3-4-4 分组更好读，"139 0000 0000"
- 字号最小 7pt 左右，检查脚本会拦下更小的字
- 头衔照实写，执业类头衔（律师、注册会计师）要和证件一致
