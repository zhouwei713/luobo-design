# 生图提示词怎么写

prompts.py 会按 spec 自动写好三个模型的提示词，这里讲背后的规则，方便你在 art.subject 里写好主体描述，也方便用户单独要提示词时手写。

## 两种用途

**素材图**：只要画面，不要字。抠图素材（cutout）放进 product-hero、type-hero 版式；整幅背景（scene）给 photo-full。字全部由排版程序来排。这是默认做法，因为模型写中文小字还是常出错。

**整图**：一张图直接出完整海报。写了 concept 的海报，整图提示词按概念来写，画面、字和图怎么咬、质感、颜色、允许画的几处小字都在里面，规则见 poster-craft.md。没写 concept 的，用一个通用骨架，只让模型写大标题和优惠这种大字，地址电话留空白后期加。

整图提示词里有几条是测出来必须写的。要画的字用引号逐字给出，并且说“除了引号里的字不要写别的”；想让东西挡在字前面，要说清是哪个东西挡住哪个字的哪个部位；还要补一句每个字都得认得出，挡住的部分不超过三分之一。

## 提示词的骨架

按这个顺序写，缺的跳过。

1. 用途和风格锚点：这是什么物料、什么风格
2. 主体：是什么、什么材质、什么状态，越具体越好（"透明塑料杯，黑糖珍珠沉在杯底"比"一杯奶茶"强得多）
3. 场景和层次：前景、中景、背景
4. 构图：主体在哪，哪块区域要留空给文字，元素数量写准确数字
5. 要出现的文字：用引号原样写出，说明位置和字号大小，并加一句"除了引号里的字，画面上不要出现其他文字"
6. 风格和渲染：插画还是摄影，什么质感
7. 光线和镜头：摄影类才写
8. 配色：给具体色值，模型能大致对上
9. 比例
10. 不要什么：放最后一行

## 三个模型的差别

**GPT Image 2**：最听话，结构化写法效果好，用"Use case / Subject / Composition / Style / Avoid"这样分行写。尺寸只有三种，选最接近的。没有透明背景，抠图让它出纯白底，本地去背景。

**Seedream / 即梦**：中文写最好，用逗号连起来的描述句。大号中文标题基本能写对，小字仍然会出现重复字、错字。出图选 2K 以上，小字更清楚。

**Nano Banana 2**（gemini-3.1-flash-image）：写成一段自然的描述，像跟摄影师讲你要什么，比堆关键词效果好。照片感、材质、光线最强，适合 scene 背景图和产品实拍感；中文字偏弱，别让它写字。它很擅长改图，用户给了产品照片时可以让它"保持这个杯子不变，换成黄色纯色背景"。

## 多张图保持一致

一单里有好几张图时，把主体描述原封不动地复制到每个提示词里，再加一句一致性要求（"同一个杯子，同样的杯型、配料、贴纸位置"）。有参考图的模型（Nano Banana、GPT Image 2 的编辑接口）直接把第一张图作为参考。

## 不要写的

- 品牌 logo 和真实商标，模型画不对，还有侵权风险
- 真人明星、知名 IP 角色
- "高清""8K""大师作品"这类没用的词
- 和行业不搭的风格词（餐饮海报写"赛博朋克"）
