# 物料：活动海报

type 是 `poster`。开业、促销、新品、讲座、活动海报都用它，停水停电、放假安排这类正式通知用 notice 版式。

## 内容字段

| 字段 | 说明 | 建议长度 |
|---|---|---|
| kicker | 顶部小标签，说明这是什么："新店开业""新品上市""周末活动" | 2 到 6 个字 |
| headline | 主标题，必须手动断行 | 每行 8 字以内，两到三行 |
| sub | 副标题，一个真实卖点或一句补充 | 20 字以内 |
| offer | 优惠，`{"big": "第二杯半价", "small": "10月18日至20日"}` | big 5 字以内 |
| details | 信息行，`[{"k": "地址", "v": "{address}"}]` | 最多 4 行 |
| cta | 行动句，告诉人做什么 | 16 字以内 |
| qr | 二维码，`{"label": "扫码进群", "src": "qr.png"}`，没图就留占位 | |
| big_number | 只有 editorial 版式用，大号日期或数字，"10.18" | |
| org | notice 用，顶部色带里的发布单位 | |
| body | notice 用，正文，段落之间空一行（`\n\n`）。"尊敬的各位业主："这种称呼单独成段，不缩进 | 三段以内 |
| issuer、date_line | notice 用，右下角落款和日期 | |
| tags | art-hero 用，名字下面的小标签，`["新品", "冰饮"]` | 最多 4 个 |
| note | art-hero 用，右下角一行小字，常放品牌名 | |
| art_label | art-hero 和 art-frame 用，画面角上或展签里的小字，比如"水彩""NO.03 系列" | |
| big_title | type-sandwich 用，穿插用的超大标题，用 `\n` 断行 | 每行 2 到 4 字 |
| lines | type-stack 用，一行一句的列表 | 4 到 6 行 |
| looks | type-stack 用，每行的样子 ink、accent、bar、outline、serif | |

## 十种版式

**product-hero** 产品当主角。标题在上，产品在中间的圆盘上，光芒和小星星衬托，优惠贴纸贴在产品肩上，信息卡在底部。横版时左文右图，方图时上下两段、中间左文右图。适合有明星产品的店。

**type-hero** 大字当主角。超大标题占上半部，产品在中间偏右，半藏在优惠色带后面，信息直接排在底色上。适合促销力度大、要远看的海报。

**editorial** 安静的杂志版面。双线边框，所有内容居中，标题下一根强调色短线，可以放一个大号日期。适合讲座、读书会、品鉴会、高端品牌。

**photo-full** 照片铺满。需要 art.image（用户照片或 scene 模式生图），底部压暗渐变，白字叠在照片上。没有图片时自动退回 product-hero。

**notice** 正式通知。顶部一条强调色带写类别（"停 水 通 知"）和发布单位，下面是写结果的大标题，关键信息放进带色边的信息框，再往下是正文，右下角落款和日期，左下角放服务电话。横版时色带竖在左边。正文短的时候字号会自动放大，不会留一大块空白。看三个方向时这个版式保持不变，只换颜色。

**art-hero** 艺术画面当主角。竖版时整张海报跟着画风换（版式、标题字、配色、小装饰都变，见 art-styles.md 的"画风管整张海报"），方图和横图用下面这套通用排法。上面六成多是满版的艺术画面，用 art.style 选画法（水彩、剪纸、黏土、霓虹……），主体画在中间，art.ingredients 的小原料散在四周；下面是编号、名字、介绍和标签。方图和横图时画面在左、文字在右。单品海报、新品、系列图都用它，详见 art-styles.md。

**type-sandwich** 字和主体穿插。超大粗黑标题（用 big_title，没写就用 headline，一行最好 2 到 4 个字，最多两三行），主体站进标题里：大部分字在主体后面，最后一行有一个字回到主体前面，画面有前后层次。竖版标题在上方居中，主体从标题中间升起来，最后一行的第一个字在前；方图和横图标题靠左，主体站在右边，最后一行的最后一个字在前，横图时说明文字放到右侧空位。主体最好是透明底抠图（模型生成的、用户照片抠出来的），程序画的插画也能用，只是层次感弱一些。

**type-stack** 撑满大字堆。lines 写 4 到 6 行短句，每一行自动算字号，顶满左右两边，一行一种样子：looks 可以给每行指定 ink（深色）、accent（品牌色）、bar（色条反白）、outline（空心字）、serif（宋体），不写就按默认顺序轮换。行数太多放不下时整面一起缩小，右边就不再齐，所以五行左右最好看。有主体图时竖版和方图放成右下角的圆贴纸，横图放成右侧的大图。

**collage** 拼贴风。撕纸片、胶带、网点圆、手画箭头和星星，主体带一圈白色贴纸边，标题每个字剪自不同的纸片（字体、底色、角度都不同），sub 印在一张白纸条上，tags 做成圆贴纸，kicker 是一块黑胶布。对模型依赖最小，程序画的主体放进来也不违和。

上面三种都可以在 art 里加 `"deco": "tech"`，叠一层数据装饰：四角十字准星、边缘竖排编号、条形码，适合科技感、发布会、潮牌。

**art-frame** 把画装进画框，白色卡纸加细框，下面一张像美术馆展签的小标签（名字、一句话、风格和品牌）。适合做一组系列图、装饰画、小红书九宫格。

## 什么时候用哪种

- 有产品又有优惠：product-hero
- 优惠就是卖点，产品不重要：type-hero
- 活动本身是重点（时间、地点、主题）：editorial
- 有一张好照片：photo-full
- 要大家照着做的通知（停水、放假、维修、值班）：notice
- 单品、新品、一个系列每张换一种画风：art-hero
- 想要文艺、像一幅画：art-frame
- 有一张好的抠图主体，想要冲击力：type-sandwich
- 文案就是卖点，几句短话想喊出来：type-stack
- 年轻人、潮牌、自媒体、活动预告，要热闹有态度：collage

## 整张交给生图模型

配了生图模型时，海报可以写 `"mode": "ai"` 加一个 concept，由模型按创意概念连图带字一起画出来，出来的是 `<id>-<尺寸>-ai.png`。同一件物料照样按 layout 排一版，没模型、生成失败或者信息必须一字不错时用它。什么时候走哪条路，见 SKILL.md 第四步；concept 怎么想、怎么写，见 poster-craft.md 和 spec.md。

不写 mode 也可以写 concept，这时它只决定配图画什么，字还是排版程序来排。

## 尺寸

一张海报通常出两三个尺寸。版式会按横、竖、方自动重排，标题字号、产品大小、信息卡位置都会变，所以不用为每个尺寸写不同文案。手机长图（story）会更瘦长，标题区自动加高。

## 常见问题和修法

- 检查报"文字放不下"：标题太长，删字或改成三行；details 太多，删到 4 行以内
- 贴纸文字太小：offer.big 太长，压到 5 字以内
- 末行孤字：调整标题断行，或者改一两个字
- 画面太空：换 type-hero，或者加 sub 和 cta
- 产品图太小：用户的照片背景太杂，先抠图；或者换 photo-full
