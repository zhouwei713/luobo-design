# 物料：证书和奖状

type 是 `certificate`。学校奖状、荣誉证书、结业证书、员工表彰、比赛获奖证书。

## 内容字段

| 字段 | 说明 |
|---|---|
| title | "奖状""荣誉证书""结业证书"，四个字以内会自动加字距 |
| subtitle | 英文副标题，"CERTIFICATE OF HONOR"，可选 |
| recipient | 获奖人姓名 |
| recipient_suffix | 姓名后的称呼，"同学""同志""女士" |
| recipients | 多人名单，见下面"批量" |
| body | 正文，奖项前面的部分，"在 2026 年秋季运动会中奋勇拼搏，荣获" |
| award | 奖项，会用强调色加粗显示，不会被拆到两行 |
| body_after | 结尾，"特发此证，以资鼓励。" |
| issuer | 颁发单位 |
| date | 落款日期 |
| signers | 签名栏，`[{"role": "校长"}, {"role": "班主任", "name": "张老师"}]`，不写 name 就留横线手签 |
| seal | 是否留盖章位置，默认 true |
| number | 证书编号，写 `{n}` 会自动编号成 001、002…… |

body 里也可以写 `{award}` 指定奖项出现的位置。

## 批量

一个班、一批员工，名单放进 recipients（或 item 上的 batch）：

```json
"recipients": [
  {"recipient": "王小明", "award": "进步之星"},
  {"recipient": "李思源", "award": "阅读小达人"},
  "欧阳可欣"
]
```

只写名字时用 content 里统一的 award。每人一张 PNG，A4 尺寸另有 PDF，打印时按顺序就行。

## 两种版式

**classic** 传统奖状样式。粗细两道边框加四角装饰，顶部可放奖牌或奖杯插画，标题居中，姓名带下划线，正文首行缩进，签名在左下，落款和盖章位置在右下。

**modern** 左侧（竖版时上方）一整块强调色放标题和奖杯，右侧放姓名和正文，更现代，适合公司和比赛。

## 尺寸

默认 a4-landscape，竖版用 a4。

## 注意

- 盖章处只是一个虚线圆，真正的章由用户自己盖。skill 不画任何仿制的公章、印章、钢印
- 名单里的名字和奖项必须来自用户，出完逐个核对
- 学校奖状别写分数和排名
