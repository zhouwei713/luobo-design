# 物料：小红书封面

type 是 `xhs`，只做封面（笔记的第一张图），不做内页。尺寸用 `portrait`（1080×1440，3:4）。

## 先记住这几条

这些是从 11 个领域、80 张千赞以上的封面里看出来的，写文案和选结构之前先过一遍。

- 实拍最能打。点赞最高的那一批几乎都是真人、真宠物、真菜，最多压一句大字。排版很精致的信息图和配色卡，点赞多半只有几千
- 怕广告感。封面越像海报越容易被划走，要像真人自己做的
- 字用“花字”：粗胖黑体，白字或黄字，外面一圈黑描边，稍微歪一点，旁边配绿色对勾、小标签、贴纸
- 字压在衣服、背景、手上，绝不挡脸和眼睛
- 美食、宠物、家居几乎不放字，画面本身就是钩子；要放也只放一两行
- 想让人收藏的干货，封面就长得像内容本身：备忘录截图、清单、榜单，字密一点反而是信号
- 标题每行 4 到 8 个字，两行最常见；钩子靠数字、反差、身份、省时省钱、避坑，比如“每天省1小时”“0成本”“新手零失败”

## 七种结构怎么选

| layout | 是什么 | 适合 | 需要什么 |
|---|---|---|---|
| photo | 实拍照片铺满，花字标题、贴纸、对勾 | 教程、经验、美食、宠物、家居、穿搭，大多数情况 | 用户的照片；没有照片又配了生图模型时可以按 art.subject 生成，真人出镜的还是用自己的照片 |
| textcard | 纯色卡片加一句话，像小红书自带的文字卡 | 观点、情绪、一句话干货 | 只要一句话 |
| memo | 手机备忘录的样子，标题、时间、黄色对勾清单 | 攻略、行程、清单、自用合集 | items |
| ranking | 数字大标题、TOP 标签、带排名的列表 | 工具合集、好物榜、推荐榜 | items |
| grid | 四宫格或九宫格，每格一个标签，中间一张标题卡 | 探店合集、穿搭合集、一日游 | photos（用户的照片） |
| compare | 上下或左右两张对照，花字标签 | 改造前后、她做的我改的、踩坑对比 | photos 两张 |
| doodle | 米色纸、手写大字加马克笔划重点、可爱插画、小涂鸦 | 母婴、知识、清单类，想要温柔一点 | 程序插画就能做；配了模型可以按 art.subject 画插画 |

拿不准就用 photo。用户没有照片，又不想用生图模型，就从 textcard、memo、ranking、doodle 里挑，这四种完全不需要照片。

## 内容字段

| 字段 | 用在 | 说明 |
|---|---|---|
| title | 全部 | 必填。用 `\n` 断行，`**重点**` 标出要换颜色的词 |
| sub | photo、textcard、ranking、grid、doodle | 一句补充，photo 里会放在黑底黄字的小条上 |
| stickers | photo | 最多 3 个歪着的小标签，“懒人必看”“建议收藏” |
| badges | photo | 最多 3 个带绿色对勾的卖点，“0成本”“租房也能用” |
| colors | photo、doodle | 每行标题的颜色，默认白黄交替（photo）或绿橙黑（doodle） |
| title_pos | photo、grid | top 或 bottom；photo 不写时按 art.focus 自动避开脸 |
| items | memo、ranking | 字符串，或 `{"t": "标题", "d": "说明", "v": "右侧数值"}`，memo 最多 12 条，ranking 最多 10 条 |
| date、app | memo | 标题下的灰色时间，左上角的应用名（默认“备忘录”） |
| kicker、tag | ranking | 左上黑色胶囊、右上白色胶囊，比如账号名和“TOP10” |
| color | textcard、doodle | 卡片底色：green、yellow、pink、blue、cream、gray |
| align | textcard | left 或 center |
| photos | grid、compare | 图片路径，grid 里可以写 `{"src": "...", "tag": "免费", "label": "拙政园"}` |
| labels | compare | 两张图上的花字，默认“之前”“之后” |
| split | compare | lr 左右排，默认上下排 |
| font | doodle | brush 换成毛笔手写，默认圆润手写体 |
| series | 全部 | 顶部的系列编号，“#02” |
| handle | 全部 | 底部的账号名，“@萝卜AI笔记” |

art 里的字段：

- `image` 用户的照片
- `focus` 照片里脸或主体的位置 `[x, y, 宽, 高]`，都是 0 到 1 的比例。**用了真人照片一定要先看图把这个填上**，标题会自动放到另一边。没填时按脸在画面中上部处理
- `subject` / `subject_en` 没有照片时让生图模型画什么（photo 生成照片，doodle 生成插画）
- `motif` 没有照片也没有模型时的程序插画，doodle 默认用它

## 一个系列

同一个账号连着发，用 batch 一次出一组，结构不变只换字：

```json
{"id": "daily-ai", "type": "xhs", "layout": "textcard", "sizes": ["portrait"],
 "content": {"color": "blue", "handle": "@萝卜AI笔记"},
 "batch": [{"title": "每天认识一个AI工具\n**Claude**", "series": "#01"},
           {"title": "每天认识一个AI工具\n**Kimi**", "series": "#02"}]}
```

## 不要做的

- 封面上不写微信号、“加V”“私信领取”“淘宝搜”这类把人引到站外的话，小红书会限流，检查会提醒
- 广告法极限词照样不能用，“最好吃”“第一”会报错
- 别用生图模型生成假的真人“亲测”照片冒充本人，真人出镜用用户自己的照片
- 用别人的图要确认能用，参考库里的封面只用来学做法，不能直接拿来改
