# 物料：桌号牌和席位卡

type 是 `tablecard`。婚宴、寿宴、年会、会议都会用到。两种版式都是印刷品，带 2mm 出血，出 300dpi PNG 加 PDF。

## 两种版式

**number** 桌号牌，立在桌子中间。尺寸 `table-card`（100x150mm），超大桌号居中，下面是"号桌"，再往下可以列这桌的宾客名，底部写日期。

**tent** 席位卡，对折立在每个座位前。尺寸 `tent`（100x120mm），中间一条虚线是折痕，上半部分倒着排，折起来以后两面都是正的，对面坐的人也能看到名字。

## 内容字段

| 字段 | 版式 | 说明 |
|---|---|---|
| number | number | 桌号，"1"、"主桌"都行 |
| label | number | 桌号下的小字，默认"号桌"，年会可以写"TABLE" |
| guests | number | 这桌的宾客名单，列表，最多 10 人左右 |
| name | tent | 宾客名字或称呼 |
| role | tent | 名字下的小字，"诚挚邀请""嘉宾""主讲人" |
| event | 两种都有 | 活动名，"林知远 & 陈晚晴 婚宴" |
| date | number | 日期，放底部 |

## 批量

一桌一张、一人一张，都用 batch。

```json
{"id": "table", "type": "tablecard", "layout": "number", "sizes": ["table-card"],
 "batch": [{"number": "1", "guests": ["林建国", "周淑芬"]}, {"number": "2", "guests": ["王海", "王丽"]}],
 "content": {"label": "号 桌", "event": "林知远 & 陈晚晴 婚宴", "date": "2027.05.22"}}
```

席位卡的 batch 可以直接写名字列表，`"batch": ["王叔叔", "李老师"]`，每个名字出一张。

桌号牌的 batch 只写字符串时，会当成桌号。

## 印刷提示

- 交给打印店时说明"带 2mm 出血，按裁切线裁"
- 席位卡用 250g 以上的卡纸，对折处最好压痕
- 桌号牌常配亚克力或金属支架，100x150mm 是常见的支架尺寸，用户的支架尺寸不同时改 platforms.json 或用自定义尺寸

## 常见问题

- 宾客名太多挤不下：每桌超过 10 人时，桌号牌只写桌号，名单另做一张总表（menu list，不写价格）
- 名字是四个字以上的外国名：tent 版式会自动缩字，太长就只写姓加称呼
