# 物料：邀请函

type 是 `invitation`。年会、家长会、开业、发布会、答谢会、讲座、婚宴寿宴，出的是图片和印刷 PDF。要发微信、让人点了能导航和回复出席的电子版，另加一件 h5，见 @references/item-h5.md。

## 内容字段

| 字段 | 说明 |
|---|---|
| kicker | 顶部小字，"INVITATION""家长会邀请""ANNUAL GALA 2026" |
| title | 活动标题，必填，手动断行 |
| big_number | 大号日期，"01.16"，可选 |
| guest | 称呼对象，会显示成"尊敬的 xxx：" |
| salutation | 想自己写整句称呼时用，会替代 guest |
| body | 邀请正文，两三句话 |
| details | 信息行：时间、地点、着装、联系人 |
| rsvp | 回复要求，"请于 1 月 10 日前回复" |
| closing | 结束语，"恭候光临""期待与您见面" |
| host | 落款单位或人 |
| date_line | 落款日期 |
| qr | 报名或导航二维码 |

## 一人一张

给重要嘉宾的邀请函常要写上名字。item 上加 `batch`，每项是一个人：

```json
"batch": [{"guest": "张总"}, {"guest": "李老师"}, "王女士"]
```

字符串会当作 guest。每人生成一张，文件名带序号。

## 两种版式

**formal** 双线边框加四角装饰，居中标题，正文和信息在下方，落款在右下。横版时左边标题、右边正文。适合年会、家长会、答谢会。

**split** 上方（横版时左侧）是一整块强调色，放标题和日期，插画压在色块边缘；下方是正文和信息。更活泼，适合开业、活动、讲座。

## 尺寸

发微信用 portrait 或 story，打印用 a5，横版用 landscape 或 a4-landscape。

## 写作要点

- 正文别太长，交代"为什么请你"和"来了有什么"就够
- 时间写到几点几分，地点写到楼层房间
- 有着装要求一定写，有停车信息可以写进 details
