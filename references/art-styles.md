# 艺术风格

视觉方向管的是整套物料的颜色、字体和气质，艺术风格管的是画面里那张图怎么画。两者可以自由搭配，同一个品牌的 10 款饮品，可以每款换一种画法，颜色和字体照样统一。

在 item 的 art 里写 `"style": "watercolor"` 就行。

## 没有生图模型时

全部用 SVG 滤镜、渐变和程序生成的图形画出来，换哪台电脑效果都一样。插画库里的每一个 motif（奶茶杯、胡萝卜、囍字、奖杯……）都能套任何一种风格，背景也会跟着换成这种风格的样子。

| style | 名字 | 画出来是什么样 | 适合 |
|---|---|---|---|
| flat | 扁平插画 | 默认，干净的色块 | 什么都行 |
| watercolor | 水彩 | 边缘晕开、带颜料颗粒，背景是几团淡淡的水彩和溅点，纸纹 | 茶饮、烘焙、花店、文艺活动 |
| papercut | 剪纸 | 每样东西有白色刀口边和投影，背景是层层叠起的纸山和一轮纸太阳 | 节日、亲子、手作 |
| riso | 孔版印刷 | 两种专色错版叠印，网点和纸张颗粒，背景是大色块和条纹 | 潮流、文创、独立品牌 |
| clay | 3D 黏土 | 鼓鼓的立体感，柔光和高光，地上有影子，旁边散着黏土小球 | 甜品、儿童、可爱系 |
| lineart | 线描 | 只留等粗线条，背后错开一块色块，几笔小涂鸦 | 精品店、杂志感、极简 |
| crayon | 蜡笔手绘 | 蜡质颗粒和粗糙边，牛皮纸底，锯齿涂鸦和小星星 | 亲子、学校、童趣 |
| pop | 波普 | 粗黑描边和硬投影，放射光芒，爆炸星形，网点 | 促销、年轻人、街头 |
| neon | 霓虹 | 发光灯管线条，深色砖墙，霓虹边框 | 夜宵、酒吧、咖啡、晚上营业 |
| diffuse | 弥散光 | 几团模糊的柔光色块，主体带彩色投影 | 新品发布、美业、科技感 |
| ink | 水墨 | 淡彩水墨，边缘晕开，远山云雾，一点朱红 | 新中式、茶馆、节气 |

## 画风管整张海报

竖版的 art-hero 会按画风换掉整张海报的样子，不只是配图。品牌名、文案和颜色基调不变，所以还认得出是同一家店。

| style | 整张海报怎么变 |
|---|---|
| watercolor | 纸张底，水彩铺满全页，标题压在一团水彩里，左对齐，清秀标题宋 |
| papercut | 纸山铺在下半部，杯子站在纸山上，标题贴在一条白纸片上，标签做成挂牌 |
| riso | 超大的专色标题带错版重影，杯子叠印在上面，网点和纸纹 |
| clay | 粉彩底，杯子放在黏土台子上，标题在一颗鼓鼓的黏土胶囊里 |
| pop | 漫画格粗黑边框，杯子歪着放，爆炸星形贴纸，标题在对话框里加黑描边 |
| lineart | 大面积留白，描边的大号编号，小幅线描，细宋体标题居中 |
| crayon | 牛皮纸，手写体标题配一道蜡笔划线，标签用手画圈圈起来 |
| diffuse | 柔光色块铺底，文字放在一张磨砂玻璃卡片上 |
| ink | 宣纸，右侧竖排书法标题，红色名号块，远山 |
| neon | 深色砖墙，标题是发光灯管字，标签是霓虹胶囊 |

方图和横图暂时还是统一的 art-hero 版式。某一张不想要整页主题，在 art 里写 `"theme": false`。

## 配了生图模型时

style 会替换掉提示词里的画风描述，而且放在提示词最前面，主体也改用这种画风的说法来写（剪纸风写成"用彩色卡纸一层层剪出来"），再告诉模型不要写实、不要塑料反光这类会把画风冲掉的东西。生出来的图和程序画的样子是同一个方向。

art.subject 写"画什么"就好，比如"一杯鲜橙胡萝卜果茶，旁边两片橙子"，少写"透明塑料杯、真实冰块"这种材质细节，材质交给画风来定，不然模型会往写实走。prompts.md 里也是这套写法，用户可以复制去即梦、GPT、Nano Banana 自己生。

## 和艺术风格配套的版式

- poster 的 art-hero：上面一大块艺术画面（满版），下面是名字、介绍、标签。方图和横图时画面在左、文字在右。单品海报、新品上市用它
- poster 的 art-frame：把画装进画框，下面一张像美术馆展签的小标签。适合做系列、做装饰画、做小红书的"一组九张"

见 item-poster.md。

## 饮品杯子可以描述

motif 写 `"drink"`，再写 art.drink，就能画出不同的饮品。

```json
"art": {"style": "watercolor", "motif": "drink",
        "drink": {"liquid": ["#E9C9A0", "#B9824F"], "bits": "pearls", "top": "none", "cup": "dome"},
        "ingredients": ["pearl", "tea-leaf"]}
```

| 字段 | 可选值 |
|---|---|
| liquid | 一个或两个颜色，上浅下深 |
| layers | 写 2 就是分层饮品 |
| top | foam 奶泡、cheese 芝士奶盖、cream 奶油顶、none |
| bits | pearls 珍珠、fruit 果粒、taro 芋圆、jelly 果冻、ice 冰块、none |
| bit_color | 果粒或果冻的颜色 |
| cup | dome 球形盖、flat 平盖、hot 热饮杯 |
| label | 杯身那圈品牌色带，默认有，带一个小胡萝卜标 |

ingredients 是散在画面四周的小原料，最多 6 个，可选 orange-slice、lemon-slice、coconut、mango、jasmine、osmanthus、taro、coffee-bean、ice-cube、tea-leaf、leaf、pearl、strawberry、carrot-mini。这些名字也能单独当 motif 用。

## 怎么选

- 一个系列（10 款饮品、12 个节气）想每张都不一样，就每张换一种 style，版式和方向保持一致
- 想整套统一，就全部用同一种 style，靠不同的饮品和原料区分
- 用户说"高级""文艺"，往 lineart、watercolor、ink 走；说"可爱""好玩"，往 clay、crayon、pop 走；说"潮""酷"，往 riso、neon 走
- 霓虹和水墨自带深色或宣纸底，放在任何方向里都会自己换背景，不用改方向

## 限制

程序画的终究是"风格化插画"，水彩不会有真水彩那种偶然的漂亮，黏土也不是真的 3D 渲染。要更像真画，就配一个生图模型，或者把 prompts.md 里的提示词拿去生成，再把图放回 art.image。
